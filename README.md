# Zephyron – Agentic AI Platform
Designed and Developed by NIKHIL CHARY SRIRAMOJU

Static console (agents, RAG, CNN, tools, evals, Live AI) in `index.html`, plus an optional FastAPI backend in `api/`.

## Run locally
- Open `index.html`, or `docker compose up` then visit http://localhost:8080
- Backend: `GROQ_API_KEY=... docker compose up api`, test http://localhost:8000/health

## Free keys
Groq: console.groq.com · Gemini: aistudio.google.com. Paste into the Live AI tab. Never commit keys.

## GitHub Pages
Repo → Settings → Pages → Deploy from a branch → main / (root) → Save.

## Modules
Mission graph, RAG, CNN lab, MCP-style tools, evals, Docker, Live AI (Groq/Gemini), vector memory map, SHA-256 audit trail, installable PWA, CI tests (`api/`), `docs/ARCHITECTURE.md`.
